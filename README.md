# Youssef Alaa Abdelrady — Research Portfolio

A curated index of my applied AI and engineering projects, spanning reliable workflows, retrieval, computer vision, and evaluation. Each repository documents its implementation, evidence, and limitations.

## Research and engineering projects

- [Durable Workflow Runtime](https://github.com/Youssef-Al-eng/durable-workflow-runtime) — SQLite-backed task DAG execution with restart recovery, durable state, and idempotency keys.
- [Risk-Aware Tool Router](https://github.com/Youssef-Al-eng/risk-aware-tool-router) — Typed mock-tool selection with consequence-aware risk limits and reasoned abstention.
- [Long-Context Memory Benchmark](https://github.com/Youssef-Al-eng/long-context-memory-benchmark) — A deterministic comparison of memory strategies for retaining exact records under token budgets.
- [Domain Adapter Arena](https://github.com/Youssef-Al-eng/domain-adapter-arena) — A CPU-sized source/target classification study measuring target adaptation alongside source retention.
- [Personalized Creative Adaptation](https://github.com/Youssef-Al-eng/personalized-creative-adaptation) — A local image palette adaptation pipeline that tracks color distance, edge change, and dimensions.
- [Industrial Anomaly Localization](https://github.com/Youssef-Al-eng/industrial-anomaly-localization) — Normal-only patch statistics that produce pixel localization maps in a synthetic illumination-shift demonstration.
- [Multilingual Document Retrieval](https://github.com/Youssef-Al-eng/multilingual-document-retrieval) — Layout-aware ranking of English, Arabic, and mixed queries over document blocks with source citations.

The projects are documented with their evaluation setup and claim boundaries; generated or synthetic fixtures are identified in each repository.
